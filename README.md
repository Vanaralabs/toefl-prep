# TOEFL iBT Prep Hub 🎓

A complete, offline-ready TOEFL iBT preparation web app. Built for the German visa (B2 level, 80+ score target).

## Features

- 📝 **Speaking Templates** — Memorizable templates for all 4 speaking tasks
- ✍️ **Writing Templates** — Integrated writing + academic discussion structures
- 📖 **Reading Strategies** — Question-type breakdown and time management
- 🎧 **Listening Tips** — Note-taking system with shortcuts
- ⏱️ **Practice Zone** — Timed practice with real TOEFL-style prompts
- 📚 **Vocabulary Builder** — 50 high-frequency academic words with flashcards
- 📊 **Progress Tracker** — Log scores, track streaks, see improvement

## How to Use

### Option 1: Open Locally
Just open `index.html` in your browser. That's it. No server needed.

### Option 2: Deploy on GitHub Pages
1. Create a new repo on GitHub
2. Push all files to the `main` branch
3. Go to **Settings → Pages → Source: Deploy from branch → main → / (root)**
4. Your app will be live at `https://yourusername.github.io/repo-name/`

## Tech Stack

- Pure HTML/CSS/JavaScript (no frameworks, no build tools)
- LocalStorage for data persistence
- Responsive design (works on phone + desktop)
- Dark mode support

## Score Targets (German Visa)

| Section   | Target | Strategy |
|-----------|--------|----------|
| Reading   | 22+    | Don't read whole passage first |
| Listening | 22+    | T-chart note-taking |
| Speaking  | 20+    | Templates + 3 pre-planned stories |
| Writing   | 20+    | Structure > vocabulary |
| **Total** | **80+** | **B2 equivalent** |
